---
name: No git operations without permission
description: Never commit, push, or run any git command without explicit user approval
type: feedback
---

Do NOT run git commit, git push, git add, or any other git operation without explicit user permission.

**Why:** User wants full control over what gets committed and when.

**How to apply:** Always ask before any git operation. Stage changes mentally but never run git add/commit/push until the user says "commit" or "push".
